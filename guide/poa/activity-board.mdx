The Activity Board makes verified cross-platform Web3 contribution visible without hosting the original content.

## Use the board

1. Filter by a platform currently supported in the interface.
2. Sort available recent or popular views.
3. Open an Activity to review source metadata.
4. Select **View Original Activity** to inspect the source.
5. If eligible, use Helpful, Not Helpful, or the separate Report action.

An Activity card can display platform, original author, title, excerpt, published time, thumbnail, content type, original URL, evaluation counts, and current status when those fields are available.

<Note>
RocX does not host the original content. The board does not provide internal posts, comments, replies, direct messages, or a social graph.
</Note>

Popular visibility and final ranking can differ because verification, validity, eligible evaluation, and abuse review can affect both.
