The current guide covers the RocX MVP and testnet environment.

<Info>
Only a network displayed as available in the current RocX interface is supported for that session. This repository does not confirm a named network, RPC URL, or contract address, so none is listed here.
</Info>

## Testnet assets

Testnet tokens are used to test product flows. They do not have the same economic value, liquidity, or guarantees as mainnet assets. A testnet balance must not be described as a cash balance or a mainnet deposit.

## Before every transaction

1. Check the network shown in RocX and your wallet.
2. Check the selected asset and amount.
3. Check the destination when using Bridge.
4. Keep enough testnet gas for approval and transaction steps.
5. Confirm the transaction status in RocX and, when available, the appropriate testnet explorer.

## Product status

Features can be labeled **Available in MVP**, **Testnet**, **In Development**, **Coming Soon**, or **Under Review**. A visible future feature is not necessarily available for use.

| Status | What it means in this guide |
| --- | --- |
| Available in MVP / Testnet | The workflow is documented, but you must still confirm that it is enabled in the current interface. |
| In Development / Coming Soon / Under Review | Do not treat the feature as available until RocX enables it and publishes an official notice. |

The guide covers the current DeFi, PoA, Explore, AE, and profile workflows. Governance, Staking, and Radar are not documented as available MVP workflows. Their future status is determined by the product interface and official RocX announcements.

<Warning>
Do not assume mainnet availability, completed external audit, or support for Giwa Testnet or any other named network unless it appears in the current product and an official RocX notice.
</Warning>
