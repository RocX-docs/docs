My Page is the account hub for the currently connected wallet.

## Review your account

Depending on the current MVP interface, My Page can show the connected wallet, connected social accounts, profile, NFT Profile, DeFi Portfolio, AE Balance, AE History, PoA Activity History, Explore History, achievements, and account or security settings.

<Note>
Use only sections visible in the current product. This repository does not confirm that every possible My Page module is already enabled.
</Note>

## Common actions

- Confirm the connected wallet before reviewing balances.
- Connect or disconnect an approved social account under **Connected Accounts**.
- Set an owned NFT as the NFT Profile when that control is available.
- Open the relevant history before retrying a pending registration, game, claim, or refund.

<Warning>
Switching wallets changes the account context shown by My Page. Confirm the shortened address after every reconnect.
</Warning>
