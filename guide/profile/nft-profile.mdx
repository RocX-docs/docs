NFT Profile lets an eligible owned **ERC-721** or **ERC-1155** NFT represent the connected RocX account.

## Set an NFT Profile

<Steps>
  <Step title="Connect the owner wallet">Use the wallet that owns the NFT.</Step>
  <Step title="Open My Page">Select **Set NFT Profile** when the control is available.</Step>
  <Step title="Select an owned NFT">Choose an NFT returned by the current ownership check.</Step>
  <Step title="Verify ownership">Complete the verification or signature shown by RocX.</Step>
  <Step title="Save">Confirm that the profile updates.</Step>
</Steps>

An eligible NFT Profile Boost can be 5%, 7%, 10%, or 15% under the implemented mapping and can combine with Attendance Deposit AE Boost up to the total +30% cap. This repository does not identify current collection or tier names.

The same NFT Profile can appear in My Page, Roulette seats or winner views, Game History, and Leaderboard only where the current MVP interface implements that surface.

<Note>
The repository does not confirm current IPFS, HTTPS, SVG, PNG, JPG, WEBP, or GIF rendering support. If an image fails, keep the token contract, token ID, metadata URL, wallet, and network details for support.
</Note>
