## Protect the account

- Open RocX only from an official source and verify the domain.
- Never disclose a seed phrase or private key.
- Review the selected account, network, message, transaction, amount, and approval scope.
- Treat unexpected signature requests as suspicious.
- Use a separate test wallet for MVP/testnet activity when practical.
- Keep browser, wallet, and operating system software updated.

## Understand signatures

Wallet connection, offchain message signature, token approval, and onchain transaction are different actions. Registration, evaluation, Attendance, and claims can require message signatures; Deposit, Withdraw, Borrow, Repay, Swap, and Bridge can require transactions.

## Report malicious content

Use **Report**, not Not Helpful, for scam, phishing, impersonation, malicious content, or policy violations. Do not open a suspicious original URL merely to evaluate it.
