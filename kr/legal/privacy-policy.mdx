최종 업데이트: 2026년 9월 8일

본 개인정보처리방침은 이용자가 RocX 웹사이트와 서비스를 이용할 때 RocX가 개인정보를 처리하는 방법을 설명합니다.

## 1. 처리하는 정보

RocX는 이용자가 사용하는 기능에 따라 다음 정보를 처리합니다.

* 공개 지갑 주소, 블록체인 활동 및 지갑 검증 결과
* 연결 계정 식별정보, 공개 계정 정보 및 계정 연결에 필요한 인증정보
* 등록된 링크, 공개 콘텐츠 메타데이터, 검증 결과, 프로필 및 평가·랭킹·참여 기록을 포함한 활동 기록
* 지원 문의 시 이용자가 제공하는 정보

이 정보는 이용자, 연결된 서비스 및 공개된 출처에서 수집됩니다. RocX에 Private Key, Seed Phrase 또는 Recovery Code를 보내지 마세요.

## 2. 정보의 이용

RocX는 서비스 제공, 계정 연결, 콘텐츠 소유권 검증, 프로필과 활동 표시, 참여 기능 운영, 어뷰징 방지, 지원 요청 대응 및 법적 의무 준수를 위해 이 정보를 이용합니다.

## 3. 외부 서비스와 공개 기록

외부 Wallet, Platform 및 Protocol에는 각자의 개인정보 처리 기준이 적용됩니다. RocX는 법률상 요구되거나 이용자, 권리 또는 서비스를 보호하기 위해 합리적으로 필요한 경우 정보를 제공할 수 있습니다.

지갑 주소와 공개 블록체인 활동은 다른 정보와 결합될 경우 개인을 식별할 수 있습니다. RocX는 퍼블릭 블록체인 기록을 삭제하거나 외부 서비스가 독립적으로 통제하는 콘텐츠와 정보를 삭제할 수 없습니다.

## 4. Google 및 YouTube API 데이터

이 조항은 YouTube API 데이터를 포함한 Google 사용자 데이터에 적용되며, 본 방침의 다른 일반 조항과 내용이 다를 경우 우선 적용됩니다.

### 4.1 이용하는 서비스

RocX는 Google OAuth 2.0과 YouTube API Services를 이용합니다. YouTube 계정 연결은 선택 기능이며 이용자의 명시적인 승인 후에만 작동합니다. [Google 개인정보처리방침](https://policies.google.com/privacy)과 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)를 확인하세요.

RocX가 Google API에서 받은 정보를 이용하고 이전하는 방식은 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수합니다.

### 4.2 접근하는 Google 사용자 데이터

RocX는 승인된 연결 및 검증 기능을 제공하기 위해 다음 데이터에 접근하거나 이를 처리할 수 있습니다.

* Google 계정 식별자
* 해당 OAuth 권한을 실제로 요청하고 이용자가 승인한 경우에만 이메일 주소, 표시 이름 및 프로필 이미지
* YouTube 채널 ID, 채널 이름 및 기타 기본 채널 정보
* 이용자가 제출한 YouTube URL의 영상 ID, 제목, 채널 ID, 썸네일, URL 및 게시 정보 등 공개 메타데이터
* 승인된 연결 유지에 기술적으로 필요한 경우에만 OAuth 액세스 토큰과 갱신 토큰
* 계정 연결 상태와 연결된 채널이 제출 영상을 게시한 채널과 일치하는지 확인한 결과

YouTube 콘텐츠 접근은 읽기 전용이며 이용자가 제출한 영상의 검증으로 제한됩니다. RocX는 Google 비밀번호나 YouTube 로그인 자격증명을 수집하지 않습니다. OAuth 토큰은 비밀번호를 RocX에 제공하지 않고 연결을 승인하는 데 사용됩니다.

### 4.3 Google 사용자 데이터의 이용

RocX는 Google 사용자 데이터를 다음 목적으로만 이용합니다.

* 이용자의 YouTube 계정을 RocX에 연결하고 연결된 채널 식별
* 이용자가 제출한 공개 YouTube 영상을 해당 채널이 게시했는지 확인
* 활동 증명(PoA) 등록에 대한 검증 결과 기록
* 사칭, 중복 등록, 사기 및 어뷰징 방지
* 보안 유지 및 해당 기능에 관한 이용자 지원 요청 대응

제출한 YouTube URL은 게시 채널이 연결된 채널과 일치하는 경우에만 이용자의 PoA 활동으로 등록할 수 있습니다. 채널이 일치하더라도 보상이 보장되지는 않습니다.

RocX는 Google 사용자 데이터를 광고 또는 리타기팅, 사용자 데이터 판매, 데이터 브로커나 정보 재판매업체에 제공, 신용도 판단, 대출 결정, 범용 AI 또는 머신러닝 모델 학습, 관련 없는 분석이나 프로파일링에 이용하지 않습니다.

RocX는 이용자를 대신하여 YouTube 영상이나 기타 콘텐츠를 업로드, 게시, 수정 또는 삭제하지 않습니다. 좋아요, 댓글, 구독 또는 기타 YouTube 쓰기 작업도 수행하지 않습니다.

### 4.4 공유, 이전 및 공개

RocX는 Google 사용자 데이터를 판매하지 않습니다. Google 사용자 데이터를 제3자에게 공유, 이전 또는 공개하는 경우는 다음으로 제한됩니다.

* 이용자가 승인한 기능 운영에 필요한 범위에서 이용자의 동의에 따라 RocX의 지시를 받아 처리하는 호스팅, 데이터베이스, 인프라, 보안 및 지원 서비스 제공업체
* 보안 사고, 사기 또는 서비스 악용 조사
* 적용 법률, 법원 명령 또는 적법한 정부 요청 준수
* 적용 법률, 필요한 고지 및 이용자의 명시적 사전 동의를 충족한 합병, 인수 또는 자산 이전

서비스 제공업체는 계약상 기밀유지 및 보안 의무를 부담합니다. Google 사용자 데이터를 자체 광고나 독립적인 목적으로 이용할 수 없습니다. 위 예외에도 Limited Use 요건이 적용됩니다.

### 4.5 보존 및 삭제

OAuth 액세스 토큰과 갱신 토큰은 YouTube 계정이 RocX에 연결된 동안에만 보관합니다. 연결을 해제하면 RocX는 즉시 토큰 접근을 철회하고 활성 시스템의 토큰을 지체 없이 삭제합니다.

Google 계정 및 YouTube 채널 식별자와 OAuth로 취득한 관련 데이터는 연결 유지와 PoA 등록 검증에 필요한 동안에만 보관합니다. YouTube 연결 해제, RocX 계정 삭제 또는 데이터 삭제 요청 시 활성 시스템의 관련 Google 사용자 데이터를 30일 이내에 삭제하거나 비식별화합니다. 다만 아래의 더 짧은 YouTube 삭제 기한이 우선 적용됩니다.

YouTube API 데이터는 연결 해제, 계정 삭제 또는 삭제 요청 대상이 된 경우 가능한 한 빨리, 늦어도 7일 이내에 삭제합니다. Google 계정 권한 페이지에서 접근을 철회한 경우 해당 API 데이터는 가능한 한 빨리, 늦어도 철회 후 30일 이내에 삭제합니다. RocX는 승인 유효성을 주기적으로 확인하고 승인을 갱신할 수 없으면 관련 데이터를 삭제합니다. 저장된 YouTube 채널 및 영상 메타데이터는 30일 이내에 갱신하거나 삭제합니다.

제한된 백업 사본은 재해 복구 주기에 따라 최대 90일 동안 남아 있을 수 있으며 이후 삭제하거나 덮어씁니다. 이 백업 기간은 더 짧은 YouTube API 삭제 기한을 연장하지 않습니다. 해당 YouTube API 데이터는 백업 사본을 포함하여 정해진 삭제 기한 내에 삭제해야 합니다.

사기 방지, 보안 사고 조사 또는 법적 의무로 더 긴 보존이 필요한 경우 필요한 최소한의 정보만 제한적으로 보관하고 목적이 종료되면 삭제합니다. 이 예외는 적용 법률과 Google 및 YouTube 정책이 허용하는 범위에서만 적용됩니다.

이용자가 직접 제출한 공개 URL과 퍼블릭 블록체인 기록은 Google OAuth로 취득한 데이터와 구분됩니다. 이 구분이 API에서 취득한 메타데이터를 위 삭제 기준에서 제외하는 것은 아닙니다. RocX는 변경 불가능한 온체인 기록을 삭제할 수 없지만 가능한 범위에서 Google 계정과의 연결 및 RocX 내부 식별정보를 제거합니다. RocX에서의 삭제는 YouTube가 보유한 콘텐츠나 데이터를 삭제하지 않습니다. YouTube 데이터 삭제에는 YouTube의 자체 기능을 이용해야 합니다.

### 4.6 이용자 통제 및 권한 철회

이용자는 다음 방법으로 접근 권한을 철회하거나 삭제를 요청할 수 있습니다.

* RocX에서 YouTube 계정 연결 해제
* [Google 계정 권한 페이지](https://myaccount.google.com/permissions)에서 RocX 접근 권한 철회
* RocX 계정 삭제
* **[rocx@rocx.io](mailto:rocx@rocx.io)**로 Google 또는 YouTube 데이터 삭제 요청

Google 권한 철회만으로 RocX에 이미 저장된 모든 데이터가 그 즉시 자동 삭제되지는 않을 수 있습니다. 저장된 데이터의 삭제를 직접 요청하려면 RocX에서 YouTube 연결을 해제하거나, RocX 계정을 삭제하거나, 이메일로 요청하세요. Google 권한 철회 대상 데이터에는 별도 요청이 없어도 위 삭제 기한이 적용됩니다.

### 4.7 보안

RocX는 Google 사용자 데이터를 보호하기 위해 전송 중 암호화, 제한된 접근 통제, 승인 및 자격증명 보호조치, 로깅 및 보안 모니터링 등 합리적인 기술적·관리적 보호조치를 사용합니다. 접근은 서비스 운영 또는 보호에 필요한 담당자와 처리업체로 제한됩니다. 사람이 Google 사용자 데이터를 열람하는 경우는 지원을 위한 특정 데이터 열람에 대한 이용자의 명시적 동의, 보안상 필요 또는 법적 의무 등 Limited Use 요건이 허용하는 경우로 제한됩니다. 온라인 서비스는 절대적인 보안을 보장할 수 없습니다.

## 5. Meta 플랫폼 데이터 (Facebook, Instagram 및 Threads)

이 조항은 관련 Meta 연동이 제공되고 이용자가 자발적으로 RocX에 연결한 경우에 적용됩니다. Meta API로 취득한 데이터에 적용되며 본 방침의 일반 조항과 충돌하면 우선합니다. 향후 연동의 운영 기준을 설명하며, 모든 연동이 현재 제공되거나 승인되었다는 의미는 아닙니다.

### 5.1 서비스와 승인

제공되는 연동에서 RocX는 Meta의 승인 절차와 공식 API를 이용하여 지원되는 Facebook 계정 또는 Page, Instagram 계정, Threads 계정을 활동 증명(PoA) 검증에 연결합니다. 플랫폼마다 API, 권한, 지원 계정 유형 및 심사 요건이 다릅니다.

요청 권한은 플랫폼과 계정 유형에 따라 다르며 승인 화면에 표시됩니다. RocX는 연결 계정 식별과 이용자가 제출한 콘텐츠 검증에 필요한 최소 권한만 요청합니다. Instagram은 해당 API가 요구하는 경우 Business 또는 Creator 등 지원되는 Professional Account가 필요합니다. Facebook 계정 또는 Page 지원은 이용 가능한 API와 승인 범위에 한정되며 모든 개인 프로필, Page 또는 공개 URL에 대한 접근을 의미하지 않습니다.

RocX는 게시, 수정, 삭제, 좋아요, 댓글, 메시지 전송, 팔로우 또는 기타 소셜 행동 권한을 요청하지 않으며 이용자를 대신하여 광고를 관리하지 않습니다. Threads 검증은 최소 읽기 접근을 기준으로 설계하며 `threads_content_publish`를 요청하지 않습니다.

### 5.2 접근하는 Meta 플랫폼 데이터

연동과 승인한 권한에 따라 다음 데이터를 처리할 수 있습니다.

* 플랫폼별 사용자 또는 계정 ID
* 해당 API가 제공하는 사용자명, 표시 이름 및 프로필 이미지
* OAuth 액세스 토큰, 토큰 만료 정보 및 연결 상태
* 연결 계정 소유의 게시물 또는 미디어에 관한 ID, 고유 링크, 작성자 또는 계정 ID, 게시 시각, 미디어 유형, 캡션, 제목, 썸네일 및 공개 상태 등 API가 제공하는 메타데이터
* 연결 계정과 PoA 제출 작성자의 일치 결과 및 제한적인 사기 방지·검증 기록

API가 제출된 공개 URL의 직접 조회를 지원하지 않는 경우, RocX는 해당 콘텐츠를 찾고 검증하기 위해 연결 계정의 제한된 게시물 또는 미디어 목록을 일시적으로 처리할 수 있습니다. 검증 완료 후 관련 없는 게시물 메타데이터를 의도적으로 보관하지 않습니다. 연결되지 않은 계정의 임의 게시물 수집을 허용하는 것은 아닙니다.

RocX는 Facebook, Instagram 또는 Threads 비밀번호를 수집하지 않으며 이 연동으로 비공개 메시지, 연락처, 광고 데이터 또는 관련 없는 비공개 콘텐츠에 접근하지 않습니다.

### 5.3 처리 목적

Meta 플랫폼 데이터는 다음 목적으로만 이용합니다.

* 이용자가 승인한 계정 연결 및 식별
* 제출된 공개 게시물을 연결 계정이 게시했는지 검증
* 사칭, 중복 제출, 사기 및 어뷰징 방지
* 해당 PoA 검증 결과 기록 및 관리
* 연동의 보안, 문제 해결 및 이용자 지원

RocX는 Meta 플랫폼 데이터를 광고, 리타기팅, 데이터 중개, 신용평가, 대출 결정 또는 범용 AI·머신러닝 모델 학습에 이용하지 않습니다.

### 5.4 공개 표시와 블록체인 데이터

공개 PoA 기능은 이용자가 제출한 공개 URL, 승인된 공개 계정명, 제한적인 공개 메타데이터 및 검증 결과를 프로필, 활동 보드, 랭킹 또는 관련 화면에 표시할 수 있습니다.

OAuth 액세스·갱신 토큰, App Secret, 내부 인증정보, 비공개 Meta 데이터, 공개할 필요가 없는 Meta 사용자 ID 및 보안·어뷰징 탐지 원본 데이터는 공개하지 않습니다. 토큰, 비공개 계정 정보 및 비공개 Meta 데이터는 퍼블릭 블록체인에 기록하지 않습니다.

향후 온체인 증명을 도입한다면 개인정보 검토를 거친 최소화된 증명값, 상태 또는 해시로 제한합니다. 현재 구현되었다는 의미는 아니며 해시가 자동으로 익명 정보가 되는 것도 아닙니다. RocX는 불변 퍼블릭 블록체인 기록을 삭제할 수 없지만 기술적으로 가능한 범위에서 삭제된 계정 데이터와의 내부 연결을 제거합니다.

### 5.5 공유와 공개

RocX는 Meta 플랫폼 데이터를 판매하거나 라이선스로 제공하거나 데이터 브로커에게 제공하지 않습니다. 위의 제한적인 공개 표시 외에 다음 대상에게 필요한 최소 데이터만 제공할 수 있습니다.

* RocX의 지시와 서면 기밀유지·데이터 보호 의무에 따라서만 처리하는 호스팅, 데이터베이스, 인프라, 보안 및 지원 서비스 제공업체
* 적용 법률, 유효한 법원 명령 또는 적법한 요청에 따른 관할 기관
* 서비스 악용 조사나 RocX 및 이용자 보호에 합리적으로 필요한 보안·사기 방지 담당자

서비스 제공업체는 자체 광고, 프로파일링, 독립적인 상업 목적 또는 범용 AI·머신러닝 모델 학습에 데이터를 사용할 수 없습니다.

### 5.6 보존과 삭제

OAuth 토큰은 해당 Meta 계정이 연결된 동안에만 보관합니다. 연결을 해제하면 추가 API 접근을 중단하고 활성 시스템의 저장된 토큰을 지체 없이 삭제합니다.

Meta 계정 식별자, 일치한 게시물 메타데이터 및 기타 Meta 데이터는 승인된 연결, PoA 검증, 사기 방지 또는 법적 의무에 필요한 동안에만 보관합니다.

RocX 계정 삭제, 유효한 삭제 요청 또는 제공되는 Meta 데이터 삭제 수단을 통한 요청 시 관련 데이터를 활성 시스템에서 가능한 한 신속하게, 최대 30일 이내에 삭제하거나 비식별화합니다. 제한된 백업은 최대 90일 내에 삭제하거나 덮어쓰며 일반 업무 목적으로 복원하지 않습니다. 플랫폼 규칙이 삭제를 요구하면 비식별화로 삭제를 대신하지 않습니다.

연결 해제는 향후 API 접근을 중단하지만 직접 제출한 공개 URL이나 정산 무결성·중복 및 사기 방지에 필요한 비식별 기록까지 자동으로 삭제하지는 않습니다. 관련 개인정보는 별도로 삭제를 요청할 수 있습니다. 이러한 기록은 OAuth 데이터와 구분되지만 API 메타데이터의 삭제 의무가 면제되지는 않습니다.

법률이나 진행 중인 보안·사기 조사로 보존이 필요한 경우 플랫폼 요건에 따라 최소한의 정보만 보관하고 목적이 종료되면 삭제하거나 비식별화합니다. 이 Meta 기준은 앞서 규정한 Google·YouTube의 별도 삭제 기한을 연장하지 않습니다.

### 5.7 이용자 통제와 삭제 요청

다음 방법으로 연결을 해제하거나 삭제를 요청할 수 있습니다.

* 해당 Meta 계정, Accounts Center 또는 Apps and Websites 설정에서 RocX 제거
* RocX 계정 삭제
* 제공되는 Meta 데이터 삭제 요청 수단 이용
* **[rocx@rocx.io](mailto:rocx@rocx.io)**로 삭제 요청

승인 철회는 향후 접근을 중단하지만 모든 기존 기록의 삭제 요청을 의미하지는 않을 수 있습니다. 직접 삭제를 요청하려면 [소셜 계정 데이터 삭제 안내](/kr/legal/data-deletion)를 확인하세요. 플랫폼별 삭제 사유가 발생한 데이터에는 별도 재요청 없이 위 기한이 적용됩니다.

RocX 데이터 삭제는 Facebook, Instagram 또는 Threads가 보유한 원본 콘텐츠를 삭제하지 않습니다. 원본 삭제에는 해당 서비스의 기능을 이용해야 합니다.

## 6. 보관과 보안

RocX는 서비스 제공, 보안 문제나 분쟁 대응 및 법적 의무 준수에 필요한 기간 동안 개인정보를 보관합니다. 더 이상 필요하지 않은 정보는 삭제하거나 식별할 수 없는 형태로 처리합니다.

RocX는 개인정보 보호를 위해 합리적인 관리적·기술적 보호조치를 적용합니다. 온라인 서비스는 절대적인 보안을 보장할 수 없습니다.

적용 법률에 따라 이용자는 개인정보의 열람, 정정, 삭제, 사본 수령 또는 이용 제한을 요청할 수 있습니다. 또한 처리에 반대하거나 동의를 철회하거나 관련 기관에 이의를 제기할 권리를 가질 수 있습니다.
