최종 업데이트: 2026년 9월 8일

외부 소셜 계정 연결을 해제하고 관련 개인정보 삭제를 요청하는 방법입니다. 제공되는 연동에 적용되며 언급된 모든 플랫폼의 지원을 발표하는 것은 아닙니다. 로그인 없이 안내를 읽고 이메일로 요청할 수 있습니다.

## 소셜 계정 연결 해제

RocX My Page에서 연결된 플랫폼 옆의 Disconnect를 선택하세요. 저장된 승인으로 추가 API 요청을 하지 않으며 활성 시스템의 OAuth 토큰을 지체 없이 삭제합니다. 다시 연결할 때까지 해당 연결을 통한 새 PoA 검증을 중단합니다.

연결 해제가 직접 제출한 공개 URL이나 중복·사기·정산 오류 방지에 필요한 비식별 기록의 삭제를 반드시 의미하지는 않습니다. YouTube 연결 해제 후 삭제 의무 등 [개인정보처리방침](/kr/legal/privacy-policy)의 플랫폼별 기준이 우선합니다.

## 삭제 요청

제공되는 설정에서 RocX 계정을 삭제하거나, 플랫폼에서 제공하는 데이터 삭제 수단을 이용하거나, **[rocx@rocx.io](mailto:rocx@rocx.io)**로 요청할 수 있습니다.

플랫폼 계정, 승인, Accounts Center 또는 Apps and Websites 설정에서도 승인을 철회할 수 있습니다. 철회가 모든 기존 기록의 삭제 요청은 아닐 수 있으므로 직접 삭제를 요청하려면 이메일을 보내세요. 플랫폼 철회에 따른 삭제 의무에는 별도 재요청이 필요하지 않습니다.

연결 식별에 필요한 최소 정보만 제공하세요. 예를 들어 RocX 계정 또는 지갑 주소, 플랫폼 및 공개 사용자명을 포함할 수 있습니다. 비밀번호, OAuth 액세스·갱신 토큰, App Secret, 개인키, Seed Phrase, 복구 문구 또는 인증 코드를 보내지 마세요.

RocX는 관련 계정의 통제 여부를 합리적으로 확인할 수 있으나 개인키나 Seed Phrase를 요구하지 않습니다. 이 페이지는 삭제 안내이며 자동 콜백이나 삭제 상태 조회 서비스가 아닙니다.

## 삭제 요청 대상 데이터

연동에 따라 다음 데이터가 포함될 수 있습니다.

* 저장된 OAuth 액세스·갱신 토큰
* 플랫폼별 사용자 또는 계정 식별자
* API에서 취득한 사용자명, 표시 이름 및 프로필 이미지
* 연결 계정 및 승인 상태
* API에서 취득한 일치 게시물 또는 미디어 메타데이터
* 연결 계정의 검증 결과
* 법률상 보존 의무나 그 밖의 보존 근거가 없는 개인정보

## 처리 기간

유효한 연결 해제 또는 삭제 사유 발생 시 추가 API 접근을 중단하고 활성 시스템의 OAuth 토큰을 지체 없이 삭제합니다. 그 밖의 대상 데이터는 유효한 삭제 요청 후 가능한 한 신속하게 최대 30일 이내에 삭제하거나 비식별화합니다. 플랫폼 규칙이 삭제를 요구하면 비식별화로 대신하지 않습니다.

YouTube API 데이터는 RocX 연결 해제, 계정 삭제 또는 삭제 요청 시 가능한 한 빨리 최대 7일 이내에 삭제합니다. Google 계정 권한 페이지에서 철회한 경우 관련 API 데이터를 철회 후 최대 30일 이내에 삭제합니다. [Google 및 YouTube API 데이터](/kr/legal/privacy-policy#4-google-및-youtube-api-데이터)를 확인하세요.

제한된 백업은 최대 90일 내에 삭제하거나 덮어쓰며 일반 업무 목적으로 복원하지 않습니다. 이 기간은 백업을 포함한 YouTube API 데이터의 더 짧은 삭제 기한을 연장하지 않습니다.

법률 또는 진행 중인 보안·사기·악용·분쟁 조사로 보존이 필요한 경우 플랫폼 규칙에 따라 최소 정보만 보관하고 목적 종료 시 삭제하거나 비식별화합니다. Meta 기준은 [Meta 플랫폼 데이터](/kr/legal/privacy-policy#5-meta-플랫폼-데이터-facebook-instagram-및-threads)를 확인하세요.

## 공개 링크와 블록체인 기록

직접 제출한 공개 URL은 OAuth 토큰이나 비공개 API 데이터와 구분됩니다. 정산 무결성, 중복·사기 방지 또는 법률 준수에 필요한 경우 삭제된 외부 계정과 합리적으로 다시 연결할 수 없는 비식별 기록을 보관할 수 있습니다. API 메타데이터에는 플랫폼 삭제 의무가 계속 적용됩니다.

RocX는 불변 퍼블릭 블록체인 기록을 삭제하거나 수정할 수 없습니다. 기술적으로 가능하면 삭제된 소셜 계정 데이터와 공개 기록의 내부 연결을 제거합니다. OAuth 토큰, 소셜 비밀번호 또는 비공개 플랫폼 데이터를 퍼블릭 블록체인에 기록하지 않습니다.

## 외부 플랫폼의 원본 콘텐츠

RocX 데이터 삭제는 Facebook, Instagram, Threads, YouTube, X, TikTok, Reddit 또는 다른 플랫폼의 원본 게시물, 프로필, 영상, 이미지 등을 삭제하지 않습니다. 해당 플랫폼의 계정·콘텐츠 기능을 이용해야 합니다.
