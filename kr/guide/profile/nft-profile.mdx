NFT Profile은 연결 Wallet이 소유한 **ERC-721** 또는 **ERC-1155** NFT를 RocX Profile로 사용합니다.

<Steps>
  <Step title="소유 Wallet 연결">NFT를 소유한 지갑을 연결합니다.</Step>
  <Step title="My Page 열기">기능이 표시되면 **Set NFT Profile**을 선택합니다.</Step>
  <Step title="Owned NFT 선택">현재 Ownership Check가 반환한 NFT를 선택합니다.</Step>
  <Step title="Ownership Verification">RocX가 표시하는 검증 또는 Signature를 완료합니다.</Step>
  <Step title="저장">Profile 갱신을 확인합니다.</Step>
</Steps>

Eligible NFT Profile Boost는 구현 Mapping에 따라 5%, 7%, 10%, 15%이며 Attendance Deposit AE Boost와 합산해 총 +30% Cap을 적용합니다. 현재 Collection 또는 Tier 이름은 저장소에서 확인되지 않습니다.

동일 NFT Profile은 구현된 경우에만 My Page, Roulette Seat/Winner, Game History, Leaderboard에 표시됩니다.

<Note>
현재 IPFS, HTTPS, SVG, PNG, JPG, WEBP, GIF Rendering 지원은 저장소에서 확인되지 않습니다. 이미지 실패 시 Contract, Token ID, Metadata URL, Wallet과 Network를 기록하세요.
</Note>
