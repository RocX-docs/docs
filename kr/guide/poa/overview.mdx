PoA Planet은 RocX의 Cross-Platform Participation & Contribution Layer입니다.

<Info>
Create anywhere. Prove it on RocX.
</Info>

사용자는 외부 플랫폼에서 Web3 콘텐츠를 만들고 RocX에는 원본 URL을 등록합니다. RocX는 원본 콘텐츠를 직접 호스팅하지 않습니다. 검증과 기여 기록에 필요한 Platform, Original Author, Title, Excerpt, Published Time, Thumbnail, Content Type, URL 등의 정보만 처리할 수 있습니다.

```text
외부에서 콘텐츠 생성
→ 원본 URL 등록
→ Contributor 및 Content 검증
→ 적격 Community Evaluation
→ 14일 Contributor Ranking
→ AE 배분
→ Reputation 및 Activity Identity
```

RocX는 새로운 SNS가 아닙니다. PoA 등록 화면에서 게시물 제목, 본문, 설명, 이미지, 영상, 파일, 썸네일 또는 댓글을 작성하지 않으며 외부 원본 콘텐츠 URL을 기준으로 등록합니다.
