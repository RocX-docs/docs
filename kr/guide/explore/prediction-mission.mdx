Prediction은 PvP가 아닌 Individual BTC Price Direction Mission입니다.

- Round: 60초
- 선택: **UP** 또는 **DOWN**
- Bet: 최소 100 AE, 최대 1,000 AE
- Final Price > Start Price: UP
- Final Price < Start Price: DOWN
- 동일: Draw

| 결과 | 100 AE Bet 정산 |
|---|---:|
| Win | **최종 190 AE**, Claim 시 Wallet Signature 필요 |
| Loss | **100 AE 전액 감소** |
| Draw | **100 AE Refund** |
| Server 또는 Price Data Error | Cancel 후 **100% Refund** |

Loss/Draw는 현재 구현 기준 즉시 반영되며 별도 Pre-funded Prediction Reward Pool은 없습니다.

<Steps>
  <Step title="Round 확인">BTC/USDT, 화면의 Price Source, Countdown, Start Price를 확인합니다.</Step>
  <Step title="방향 선택">UP 또는 DOWN과 100-1,000 AE를 선택합니다.</Step>
  <Step title="참여 확인">Round 종료 전 Mission Action을 승인합니다.</Step>
  <Step title="정산 대기">Server Final Price와 Start Price를 비교합니다.</Step>
  <Step title="Win Claim">필요한 Claim Signature 후 Game History를 확인합니다.</Step>
</Steps>

<Note>
현재 구현 Price Provider는 저장소에서 확인되지 않습니다. 실제 제품 표시가 없다면 Binance라고 가정하지 마세요.
</Note>
