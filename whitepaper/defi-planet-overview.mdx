The Capital Layer of RocX

DeFi Planet is the core financial layer where users create onchain capital activity through supported products such as Deposit, Lending, Swap, and Bridge.

<Info>
DeFi Planet measures capital.

PoA Planet measures contribution.
</Info>

---

## Onchain finance starts here.

DeFi Planet provides the financial context of RocX.

Supported deposits, lending activity, swaps, bridges, and other financial interactions can become part of the Capital Graph and the broader Activity Identity.

Capital activity matters, but it is not the only measure of user value.

---

## Capital and participation connect.

PoA Planet adds verified contribution and Reputation to the capital context created in DeFi Planet.

Eligible deposit requirements can also help create economically responsible participation, such as qualification for community evaluation.

The exact evaluation threshold, balance type, holding period, eligibility snapshot, and post-withdrawal treatment remain operating-policy decisions.

Activity registration and evaluation eligibility are separate policies and should not be treated as the same requirement.

---

## DeFi is a core layer, not the only outcome.

Verified contribution can support better DeFi experiences, but PoA value can also appear through Active Energy, Reputation, Activity Identity, contributor recognition, partner opportunities, Explore participation, and ecosystem access.

RocX does not create contribution data only to increase one deposit benefit.

It connects capital and participation so users can build a broader, more durable value history.
