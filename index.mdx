RocX is a **Proof of Activity-powered DeFi platform** that combines onchain capital activity with verified user participation.

RocX brings capital, contribution, and reputation into one measurable value system and supports an activity-centered blockchain community across Web2 and Web3 environments.

<Info>
**Every Web3 Activity Creates Value.**

The slogan describes RocX's direction. Value depends on meaningful activity, verification, eligibility, and applicable product policy; it is not an automatic reward promise.
</Info>
